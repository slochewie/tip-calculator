## Quick how-to: Tip Claim Calculator

Use **Claims** when you need to calculate the minimum tip claim from register sales.

1. Open the **Claims** page.
2. Select the organization for the shift.
3. Pick a **Weight Preset** when one matches the staffing state. The preset populates the register count, claim percentage, staffing slots, and role weights.
4. Enter the dollar amount for each register.
5. Assign the bartender responsible for each register.
6. Assign employees to each preset-populated on-duty role field.
7. Review the **Required claim** and **Claim breakdown** numbers.
8. Use **Preview** when you want to review the full report first, or save with **Save End of Shift Sales**.

For a one-off shift, leave the preset blank and build the register rows, staffing slots, roles, and weights directly on the Claims page.

## Quick how-to: Tip Pool Calculator

Use **Tips** when you already know the full tip pool amount and only need to distribute it.

1. Open the **Tips** page.
2. Select the organization for the shift.
3. Pick a **Weight Preset** when one matches the staffing state. The preset populates staffing slots and role weights.
4. Enter the complete **Tip pool** amount.
5. Assign employees to each preset-populated on-duty role field.
6. Review the **Tip pool**, **Role breakdown**, and **Distribution** numbers.
7. Use **Preview** when you want to review the full report first, then save the report.

For a one-off pool, leave the preset blank and build the staffing slots, roles, and weights directly on the Tips page.

## Preset note

Weight Presets are shared by Claims and Tips. Claims uses register count, claim percentage, staffing counts, and role weights. Tips uses only staffing counts and role weights, because the full pool amount is entered directly on the Tips page.
