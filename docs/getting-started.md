# Getting Started

Use this guide to complete a shift in about five minutes. Select the organization first, then choose the workflow that matches the amount you know.

- Use **Claims** when you have register sales and need the calculator to determine the required claim.
- Use **Tips** when you already know the complete tip pool amount.

## Tip Claims

1. Open **Claims**.
2. Load a **Weight Preset**, or leave it blank to build a one-off shift.
3. Enter the sales amount for each register.
4. Assign the bartender responsible for each register.
5. Assign employees to the staffing slots created by the preset.
6. Verify the **Required claim** and employee allocations.
7. Preview the completed shift, then select **Save End of Shift Sales**.

See the [Tip Claim Calculator guide](tip-claim-calculator.md) for the full workflow.

## Tip Pool

1. Open **Tips**.
2. Load a **Weight Preset**, or leave it blank to build a one-off shift.
3. Enter the complete **Tip pool** amount.
4. Assign employees to the staffing slots.
5. Verify the distribution and confirm the allocated total matches the pool.
6. Preview and save the completed shift.

See the [Tip Pool Calculator guide](tip-pool-calculator.md) for the full workflow.

## Before the first shift

If an employee is missing from a staffing selector, an assignment manager must enable Tip Calculator access and the appropriate role on the [Assignments](assignments.md) page.

If your organization regularly uses the same register count, claim percentage, staffing counts, and role weights, create a reusable [Weight Preset](weight-presets.md).

Completed shifts are available on the [Reports](reports.md) page.
