# Reports

> **New here?** Read [Getting Started](getting-started.md) first.

The **Reports** page stores completed Tip Claim and Tip Pool shifts for the selected organization.

## Find a report

1. Open **Reports**.
2. Select the organization.
3. Choose **Claims** or **Tips**.
4. Find the report by its completion date and time.
5. Open **View report details** to review registers, staff, roles, weights, and employee allocations.

Claim reports include register sales, the claim percentage, the required claim, register assignments, and the employee distribution. Tip Pool reports include the complete pool, active weights, and each employee's share.

## Correct a report

When **Correct report** is available:

1. Select **Correct report** on the saved shift.
2. Confirm that you want to reopen it in the appropriate calculator.
3. Make the required changes.
4. Preview the corrected report.
5. Save the correction.

The saved report remains unchanged until the correction is saved.

## Delete a report

Select **Delete report**, review the confirmation, and confirm the deletion. Deletion cannot be undone, so use correction when the shift should remain in reporting history with updated values.

Available correction and deletion actions depend on the user's permissions.
